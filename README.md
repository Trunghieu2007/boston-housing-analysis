# Boston Housing Data Analysis - Final Statistics Project

Final project analyzing housing values in Boston, MA using descriptive statistics, data visualizations, hypothesis testing, and regression analysis.

## Analysis Tasks
* **Task 1:** Familiarize with dataset (structure, datatypes, missing values, duplicates, correlation matrix).
* **Task 2:** Descriptive statistics and visualizations (Boxplots, Countplots, Scatter plots, Histograms).
* **Task 3:** Statistical hypothesis testing (Levene's test, Welch's T-test, One-way ANOVA, Pearson correlation, and OLS Linear Regression).
